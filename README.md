# ひらがな なぞりれんしゅう

iPad / Fire タブレット / PC のブラウザで使える、幼児向けのひらがな書き順練習Webアプリです。

## 現在の収録内容

### 基本46文字

- あ行: あ・い・う・え・お
- か行: か・き・く・け・こ
- さ行: さ・し・す・せ・そ
- た行: た・ち・つ・て・と
- な行: な・に・ぬ・ね・の
- は行: は・ひ・ふ・へ・ほ
- ま行: ま・み・む・め・も
- や行: や・ゆ・よ
- ら行: ら・り・る・れ・ろ
- わ行: わ・を・ん

### 濁音・半濁音25文字

- が行: が・ぎ・ぐ・げ・ご
- ざ行: ざ・じ・ず・ぜ・ぞ
- だ行: だ・ぢ・づ・で・ど
- ば行: ば・び・ぶ・べ・ぼ
- ぱ行: ぱ・ぴ・ぷ・ぺ・ぽ

### 拗音33組

- きゃ・きゅ・きょ、しゃ・しゅ・しょ、ちゃ・ちゅ・ちょ
- にゃ・にゅ・にょ、ひゃ・ひゅ・ひょ、みゃ・みゅ・みょ、りゃ・りゅ・りょ
- ぎゃ・ぎゅ・ぎょ、じゃ・じゅ・じょ、びゃ・びゅ・びょ、ぴゃ・ぴゅ・ぴょ

### 促音4語

- がっこう
- きって
- ざっし
- らっぱ

## マスを使った練習

- 単文字は、中央補助線のある正方形1マスで練習します。
- 拗音は縦2マスで、通常文字の次に小さい「ゃ・ゅ・ょ」を書きます。
- 小さい「ゃ・ゅ・ょ」は、専用マスの右上寄りへ小さく配置します。
- 促音は単語全体を1文字1マスの縦書きで練習します。
- 小さい「っ」は、専用マスの右上寄りへ小さく配置します。

## 文字の選び方

- 起動時は、一般的な縦書き五十音表を意識した「いちらん」を表示します。
- せいおん一覧は「あ」を右上、「ん」を左上に置き、一覧から練習する文字を直接選びます。
- 学習用の文字見本は、端末フォントではなくKanjiVG由来のパスで表示します。
- 練習画面では同じ行・系列の文字を切り替えられ、「← いちらんに戻る」で元のグループ一覧へ戻れます。

## おてがみカード

- 累計の星10個ごとに、「だいすき」「ありがとう」「またね」のおてがみカードが順番に解放されます。
- カードを解放しても星は消費しません。
- 解放済みカードでは、言葉全体を1文字1マスの縦書きで何度でも練習できます。
- カード練習では星は増えません。解放済み状態は累計星数から計算し、完成状態と解放案内を見たかだけを端末内に保存します。

## 使い方
1. 「せいおん」「゛゜の おと」「ちいさい もじ」の一覧から、練習する文字や組み合わせを選びます。
2. 緑の丸（①など）から、薄い線に沿って指またはタッチペンでなぞります。
3. 書き順・おおまかな方向・終点を確認し、正しければ次の画へ進みます。
4. 「おてほん」で書き順アニメーション、「じぶんで」で自由練習ができます。

## プライバシー
外部API、広告、アクセス解析、ログイン機能はありません。
星の数と、おてがみカードの完成・解放案内確認状態はブラウザの localStorage にだけ保存します。
