Use in this application
-----------------------
SVG path data is extracted from KanjiVG files and embedded in this application for stroke-guide rendering, stroke-order animation, and tracing evaluation. Its display size, visual styling, and integration format are adjusted for use in this child-friendly tracing application.

The KanjiVG-derived stroke data and adaptations to that data remain subject to the original CC BY-SA 3.0 terms.
